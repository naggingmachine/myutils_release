# MyUtils - All In One

**90 macOS utilities in one menu bar app.** Window snapping, screen capture, PDF/image/text editors, media conversion, clipboard history and more — each one a module you can switch on or off. Korean, English and Japanese UI.

## Overview

See the **[MyUtils overview page](https://www.myutils.app/)** for a visual tour.

### Install

1. Open the DMG and drag `MyUtils - All In One.app` into `Applications`.
2. Click the grid icon in the menu bar for the search field and category menus. Use **Settings…** to turn modules on and off.
3. Only the MyUtils icon appears at first. Add items such as the clock, CPU meter or timers under Settings > General > "Menu bar items".

### Permissions

Some modules need macOS permissions. Each module's settings page has a banner that requests them.

| Permission | Modules |
|---|---|
| Accessibility | Window Snap, clipboard paste, Snippet Expander, Hangul Fixer, emoji input, Shortcut Cheatsheet, Cursor Highlight, selected text for Speak & Translate |
| Screen Recording | Screen Capture, Screen OCR, Color Picker, Pixel Ruler, QR scanning |

| Microphone | Voice Memo |
| Administrator (root helper) | Battery Charge Limit, Website Blocker — install from the module's settings |

## Highlights

- **Desktop widgets**: 14 widgets you can pin to the desktop, with click-through, size and opacity control.
- **iCloud sync**: keep module data such as notes, journal and clipboard in iCloud Drive across Macs. Everything syncs by default; exclude modules individually.
- **Menu search**: click the menu bar icon and type into the field at the top. Korean initial-consonant search (`ㅋㄹㅂ`), synonyms and abbreviations all work. Press Return to run the first result.
- **Editors with tabs**: PDF, image and text editors each keep several documents open, with per-tab zoom, selection and undo.
- **In-app updates**: new versions are downloaded and verified (code signature, Apple notarization, developer team, version) before they are installed.
